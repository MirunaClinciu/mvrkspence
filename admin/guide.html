Pictures made simple

Add, replace or remove an image

+

Add an image

Open the page, artwork or book. Choose Choose an image in its image field. Pick a library image, or choose Upload to select one from your computer. Select it and confirm your choice.

↻

Replace an image

Expand the item you want to change and choose Replace image. Select the new picture. Your text and product formats stay in place.

−

Remove it from a page

Choose Remove image for an optional image. To remove a gallery picture, homepage picture or complete artwork, use that list entry’s Remove control. Save and publish the page.

Uploading puts a file in your image library. To show it on the website, select it in a page, artwork or book. Removing an image from a page keeps its file in the library, ready to reuse.

Manage or delete files in the image library

Open Manage image library to upload files and see existing pictures. To delete an unused file completely, select it and choose Delete selected. Check that no page or product still uses it first; a shared file may be used in several places.

An artwork or book needs an image. Replace its picture, hide the listing, or remove the whole listing instead of leaving its required image empty.

One image, four ways to offer it

Add or update artwork

  1. Open Photographs & shop settings from the manager. Under Photographs & artwork, choose Add photograph. To edit existing work, expand its title.
  2. Enter the title and description, then choose the photograph. Upload it once; the same picture is reused for its print, T-shirt, framed print and canvas.
  3. Expand Formats & sizes. A new photograph starts with four enquiry-only formats. Change their sizes and prices. Use Add format for another size, or remove formats you do not want.
  4. For a format you want to sell, enter a price above zero, then switch Enable checkout for this format on. Leave it off to accept enquiries. Use Offer this format to show or hide that size.
  5. Choose Save, check the picture and product previews, then Publish when ready.

Hide it for now

Switch Show this photograph on Artwork off. Its image, text and formats remain in the editor so you can bring it back later.

Remove the listing

Use Remove on the photograph entry, then save and publish. The uploaded image remains in the library.

Keep Test shop with sample products on while practising. The editable “Ravens in the Mist” listing uses sample prices: print £25, framed print £60, T-shirt £28 and canvas £70. Replace example sizes and prices before real sales.

Product previews show where your image appears. You arrange physical printing, production and shipping; the website does not order from a printing company automatically.

Books have their own editor

Add or update a book

  1. Open Books and choose Add book, or expand an existing book.
  2. Enter its title and description, then choose or upload the cover. Include edition, binding and dimensions in the description if useful.
  3. Set Price per book. Leave Enable PayPal checkout off for enquiries, or switch it on after entering a price above zero. Books share the shop currency and shipping settings.
  4. Save, check the preview and publish. Use Show this book to hide a book, or Remove to remove its listing.

Artwork and Books are saved and published separately. You never need to create or edit their internal references.

Finish your update

Save. Check. Publish.

  1. Save your draft. Wait for Changes saved. Save becomes available after you change a field.
  2. Check the preview. Review the words, pictures, sizes and prices inside the editor. Return to the form to make any adjustments.
  3. Publish when ready. Use Publish to send that page’s changes to the website. A saved draft alone does not change the live page.
  4. View the website. Allow the website update to finish, then refresh the live page. If hosting reports that publishing is paused, the owner must resume deployments before updates can appear.

Quick answers

Common questions

How do I sign in or reset my password?

Open the website manager and use the email address that received your administrator invitation. Accept the invitation to choose your password the first time. Use the password reset option if you forget it. Website editor access is separate from a Netlify hosting account.

I uploaded a picture. Why is it not on Artwork?

The image library stores files. Open Photographs & shop settings, add or expand a photograph entry and select that image. Enter its title, description and formats, then save and publish.

Why will my changes not save?

Look for the message next to a field. Required titles, images and complete product formats must be filled in. An item with checkout switched on needs a price above zero, with no more than two decimal places. If Save is grey, there are no new changes to save.

Can I keep a work in progress?

Yes. Save it as a draft and leave it unpublished. The Show switches hide completed listings from visitors after you publish the page; use drafts for work that is not ready to share.

I published, but I still see the old page.

Wait for the website update to finish, then refresh. If it still has not changed, the website owner should check the Netlify deployment. Saved content and uploads can work while production deployments are paused.

Can I test a card payment?

Keep the shop in test mode and connect a Sandbox app in PayPal payments. Use PayPal sandbox buyer or generated test-card details. PayPal decides which card options are available; never use a real card for a sandbox test.
